14. Async I/O Libraries

LibraryCategoryDescription
asyncioStdlibEvent loop, tasks, futures, queues, synchronization primitives
aiohttpHTTPAsync HTTP client + server. WebSocket support.
httpxHTTPModern async/sync HTTP client. Replaces requests + aiohttp client.
aiofilesFile I/OAsync file read/write operations.
asyncpgDatabaseUltra-fast async PostgreSQL driver (fastest Python PG driver).
aiomysqlDatabaseAsync MySQL driver based on PyMySQL.
motorDatabaseAsync MongoDB driver (official).
aioredis / redis-pyCacheAsync Redis client for caching, pub/sub, queues.
aiokafkaMessagingAsync Apache Kafka producer/consumer.
websocketsWebSocketHigh-level async WebSocket client and server.
uvloopPerformanceDrop-in replacement for asyncio event loop. 2-4x faster.
anyioCompatibilityStructured concurrency. Works with asyncio, trio, curio.
trioAlternativeAlternative async library with stricter structured concurrency.

14.1 Common Patterns

# Producer-consumer with asyncio.Queue
async def producer(queue):
for item in data:
await queue.put(item)
await queue.put(None)  # sentinel
async def consumer(queue):
while (item := await queue.get()) is not None:
await process(item)
queue = asyncio.Queue(maxsize=100)
await asyncio.gather(producer(queue), consumer(queue))
# Connection pooling
pool = await asyncpg.create_pool(DATABASE_URL, min_size=5, max_size=20)
async with pool.acquire() as conn:
rows = await conn.fetch('SELECT * FROM users WHERE active = $1', True)
