Section 01

First Steps

FastAPI is a modern, high-performance Python web framework built on top of Starlette (async) and Pydantic (validation). It generates OpenAPI docs automatically and is one of the fastest Python frameworks available.

Install & run

pip install fastapi
pip install "uvicorn[standard]"   # ASGI server
# or install everything:
pip install "fastapi[all]"

# Run dev server (auto-reload):
fastapi dev main.py
# or:
uvicorn main:app --reload

Minimal application

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}
Automatic interactive docs — zero config
  • Swagger UI — http://127.0.0.1:8000/docs
  • ReDoc — http://127.0.0.1:8000/redoc
  • OpenAPI JSON — http://127.0.0.1:8000/openapi.json

HTTP method decorators

@app.get("/items")        # read
@app.post("/items")       # create
@app.put("/items/{id}")   # full update
@app.patch("/items/{id}") # partial update
@app.delete("/items/{id}")# delete

Key features at a glance

Async-first

Built on Starlette/ASGI. Use async def for non-blocking I/O. Mix def and async def freely — FastAPI runs sync functions in a thread pool automatically.

Type-driven validation

Python type annotations are the source of truth. FastAPI + Pydantic validate, parse, and document everything from them — no separate schema files needed.

OpenAPI compliant

Every route is automatically included in the OpenAPI schema. Swagger UI, ReDoc, and client SDK generation work out of the box.

Performance

On par with Node.js and Go for async I/O workloads. One of the fastest Python frameworks, powered by async Python and Pydantic v2 (Rust-compiled core).

Request lifecycle

HTTP Request
Middleware (CORS, logging, etc.)
Route matching + path param parsing
Dependency injection (resolved)
Request body + query param validation
Path operation function executes
Response model filtering + serialisation
HTTP Response
Section 02

Path & Query Parameters

FastAPI reads parameter declarations directly from function signatures. Path parameters come from the URL template; everything else without a body type is treated as a query parameter.

Path parameters

from fastapi import FastAPI

app = FastAPI()

# Basic — string by default
@app.get("/items/{item_id}")
async def read_item(item_id: str):
    return {"item_id": item_id}

# Typed — auto-parsed and validated
@app.get("/items/{item_id}")
async def read_item(item_id: int):      # GET /items/foo → 422 Validation Error
    return {"item_id": item_id}         # GET /items/3   → {"item_id": 3}

# Path containing slashes — use :path converter
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}     # /files/home/user/doc.txt ✓
Order matters — fixed paths before parameterised ones /users/me must be declared before /users/{user_id}, otherwise me is matched as the user ID.

Enum path parameters

from enum import Enum
from fastapi import FastAPI

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet  = "resnet"
    lenet   = "lenet"

app = FastAPI()

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}
    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}
    return {"model_name": model_name, "message": "Have some residuals"}

Query parameters

# Any function parameter that is NOT in the path is a query parameter
@app.get("/items/")
async def read_items(skip: int = 0, limit: int = 10):
    return fake_db[skip : skip + limit]   # GET /items/?skip=20&limit=5

# Optional query parameter (None = not required)
from typing import Optional

@app.get("/items/{item_id}")
async def read_item(item_id: str, q: Optional[str] = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}

# Boolean query params — FastAPI converts: 1/True/true/on/yes → True
@app.get("/items/{item_id}")
async def read_item(item_id: str, short: bool = False):
    item = {"item_id": item_id}
    if not short:
        item["description"] = "This is a long description..."
    return item

Combining path, query, and body

from pydantic import BaseModel

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float

# FastAPI distinguishes them automatically:
# item_id → path param (in URL template)
# q       → query param (simple type, has default)
# item    → request body (Pydantic model)
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, q: str | None = None):
    result = {"item_id": item_id, **item.model_dump()}
    if q:
        result.update({"q": q})
    return result
Section 03

Request Body & Pydantic Models

Define your data shapes as Pydantic models. FastAPI uses them to parse the JSON body, validate types, return clear error messages, and generate OpenAPI schemas — all from a single class definition.

Basic model

from fastapi import FastAPI
from pydantic import BaseModel

class Item(BaseModel):
    name: str                       # required
    description: str | None = None  # optional
    price: float                    # required
    tax: float | None = None        # optional

app = FastAPI()

@app.post("/items/")
async def create_item(item: Item):
    item_dict = item.model_dump()
    if item.tax is not None:
        item_dict["price_with_tax"] = item.price + item.tax
    return item_dict

Nested models

from pydantic import BaseModel, HttpUrl

class Image(BaseModel):
    url: HttpUrl          # validated URL
    name: str

class Item(BaseModel):
    name: str
    price: float
    tags: list[str] = []           # list of strings
    image: Image | None = None     # nested model

class Offer(BaseModel):
    name: str
    items: list[Item]              # list of nested models

@app.post("/offers/")
async def create_offer(offer: Offer):
    return offer

Multiple body parameters

from fastapi import Body
from typing import Annotated

class Item(BaseModel):
    name: str
    price: float

class User(BaseModel):
    username: str
    full_name: str | None = None

# FastAPI expects: {"item": {...}, "user": {...}, "importance": 5}
@app.put("/items/{item_id}")
async def update_item(
    item_id: int,
    item: Item,
    user: User,
    importance: Annotated[int, Body()],  # scalar body param needs Body()
):
    return {"item_id": item_id, "item": item, "user": user, "importance": importance}

Pydantic Field — per-field validation & metadata

from pydantic import BaseModel, Field

class Item(BaseModel):
    name: str
    description: str | None = Field(default=None, max_length=300)
    price: float = Field(gt=0, description="Price must be greater than zero")
    tax: float | None = None

Model methods

item = Item(name="Foo", price=10.5)

item.model_dump()              # → dict
item.model_dump_json()         # → JSON string
item.model_copy(update={"price": 12.0})  # shallow copy with overrides
Item.model_validate({"name": "Bar", "price": 5.0})  # from dict
What FastAPI does automatically with Pydantic models Reads the JSON body, converts types, validates constraints, raises 422 Unprocessable Entity with detailed errors if invalid, provides the data as a typed Python object, generates JSON Schema, and adds request/response examples to the OpenAPI docs.
Section 04

Validation & Extra Types

Use Query(), Path(), and Header() with Annotated to add constraints, metadata, and aliases to individual parameters.

Query parameter validation

from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(
        min_length=3,
        max_length=50,
        pattern="^fixedquery$",
        title="Query string",
        description="Query string for filtering items",
    )] = None
):
    return {"q": q}

# Required query param (no default)
@app.get("/items/")
async def read_items(q: Annotated[str, Query(min_length=3)]):
    return {"q": q}

# List of values: GET /items/?q=foo&q=bar
@app.get("/items/")
async def read_items(q: Annotated[list[str], Query()] = ["foo", "bar"]):
    return {"q": q}

Path parameter validation

from fastapi import Path

@app.get("/items/{item_id}")
async def read_item(
    item_id: Annotated[int, Path(
        title="The ID of the item",
        ge=1,       # greater than or equal to 1
        le=1000,    # less than or equal to 1000
    )],
    q: str | None = None,
):
    return {"item_id": item_id, "q": q}

Header parameters

from fastapi import Header

@app.get("/items/")
async def read_items(
    user_agent: Annotated[str | None, Header()] = None,
    x_token: Annotated[list[str] | None, Header()] = None,   # X-Token repeated
):
    return {"User-Agent": user_agent, "X-Token values": x_token}
# FastAPI converts header names: user_agent → User-Agent automatically

Cookie parameters

from fastapi import Cookie

@app.get("/items/")
async def read_items(ads_id: Annotated[str | None, Cookie()] = None):
    return {"ads_id": ads_id}

Section 05

Dependency Injection

FastAPI's dependency injection system lets you share logic — database connections, auth checks, pagination — across routes with zero boilerplate. Dependencies are plain functions; FastAPI resolves them automatically.

Basic dependency

from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

# Dependency — same signature rules as a path operation
async def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}

CommonsDep = Annotated[dict, Depends(common_parameters)]

@app.get("/items/")
async def read_items(commons: CommonsDep):
    return commons

@app.get("/users/")
async def read_users(commons: CommonsDep):
    return commons

Class-based dependencies

class CommonQueryParams:
    def __init__(self, q: str | None = None, skip: int = 0, limit: int = 100):
        self.q = q
        self.skip = skip
        self.limit = limit

@app.get("/items/")
async def read_items(commons: Annotated[CommonQueryParams, Depends(CommonQueryParams)]):
    # shortcut: Depends() with no argument infers the type
    # async def read_items(commons: Annotated[CommonQueryParams, Depends()]):
    return {"q": commons.q, "skip": commons.skip, "limit": commons.limit}

Nested / sub-dependencies

async def query_extractor(q: str | None = None):
    return q

async def query_or_body(
    q: Annotated[str | None, Depends(query_extractor)],
    last_query: str | None = None,
):
    return q or last_query

@app.get("/items/")
async def read_items(query: Annotated[str | None, Depends(query_or_body)]):
    return {"q": query}

Dependencies on path operations (no return value needed)

from fastapi import Depends, Header, HTTPException
from typing import Annotated

async def verify_token(x_token: Annotated[str, Header()]):
    if x_token != "fake-super-secret-token":
        raise HTTPException(status_code=400, detail="X-Token header invalid")

async def verify_key(x_key: Annotated[str, Header()]):
    if x_key != "fake-super-secret-key":
        raise HTTPException(status_code=400, detail="X-Key header invalid")
    return x_key

# Both dependencies run on every request to this route
@app.get("/items/", dependencies=[Depends(verify_token), Depends(verify_key)])
async def read_items():
    return [{"item": "Foo"}, {"item": "Bar"}]

Dependencies with yield — lifespan resources

from sqlalchemy.orm import Session
from .database import SessionLocal

def get_db():
    db = SessionLocal()
    try:
        yield db          # ← everything before yield = setup
    finally:
        db.close()        # ← everything after yield = teardown

@app.get("/items/")
async def read_items(db: Annotated[Session, Depends(get_db)]):
    return db.query(Item).all()
Apply dependencies globally app = FastAPI(dependencies=[Depends(verify_token)]) — runs on every route in the app. Useful for global API key auth.
Section 06

Response Models & Status Codes

Response models let you control exactly what data is returned — filtering out internal fields, enforcing output types, and driving OpenAPI documentation — using the same Pydantic model pattern.

Response model via return type annotation

from pydantic import BaseModel

class UserIn(BaseModel):
    username: str
    password: str       # input model — has password
    email: str

class UserOut(BaseModel):
    username: str
    email: str          # output model — NO password field

@app.post("/users/", response_model=UserOut)
async def create_user(user: UserIn) -> UserOut:
    # Even if you accidentally return password, FastAPI filters it out
    return user

response_model_exclude / response_model_include

@app.get("/items/{item_id}", response_model=Item,
         response_model_exclude={"tax"},          # exclude specific fields
         response_model_exclude_unset=True)       # omit fields not explicitly set
async def read_item(item_id: str):
    return items[item_id]

Status codes

from fastapi import status

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(item: Item):
    return item

@app.delete("/items/{item_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_item(item_id: str):
    del items[item_id]

Custom responses

from fastapi import Response
from fastapi.responses import JSONResponse, HTMLResponse, RedirectResponse, FileResponse, StreamingResponse

# Return HTML
@app.get("/html", response_class=HTMLResponse)
async def get_html():
    return "<h1>Hello HTML</h1>"

# Return a redirect
@app.get("/old-url")
async def redirect():
    return RedirectResponse(url="/new-url", status_code=301)

# Return a file
@app.get("/download/{filename}")
async def download(filename: str):
    return FileResponse(path=f"files/{filename}", filename=filename)

# Return raw response (bypass serialisation)
@app.get("/custom")
async def custom():
    return Response(content="raw bytes", media_type="application/octet-stream")

Dynamic status code

from fastapi import Response

@app.post("/items/", status_code=201)
async def upsert_item(item_id: str, item: Item, response: Response):
    if item_id in db:
        db[item_id] = item
        response.status_code = 200   # update → 200
    else:
        db[item_id] = item           # create → 201 (default)
    return item

Error Handling & Middleware

Raise HTTPException to return error responses with the right status code and detail message. Add middleware to intercept every request and response — for CORS, logging, authentication, and more.

HTTPException

from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}

@app.get("/items/{item_id}")
async def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(
            status_code=404,
            detail="Item not found",
            headers={"X-Error": "There goes my error"},  # optional custom headers
        )
    return {"item": items[item_id]}

Custom exception handler

from fastapi import Request
from fastapi.responses import JSONResponse

class UnicornException(Exception):
    def __init__(self, name: str):
        self.name = name

@app.exception_handler(UnicornException)
async def unicorn_exception_handler(request: Request, exc: UnicornException):
    return JSONResponse(
        status_code=418,
        content={"message": f"Oops! {exc.name} did something."},
    )

@app.get("/unicorns/{name}")
async def read_unicorn(name: str):
    if name == "yolo":
        raise UnicornException(name=name)
    return {"unicorn_name": name}

Override default 422 validation error handler

from fastapi.exceptions import RequestValidationError

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    return JSONResponse(
        status_code=422,
        content={"detail": exc.errors(), "body": str(exc.body)},
    )

Middleware

import time
from fastapi import Request

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start = time.time()
    response = await call_next(request)
    response.headers["X-Process-Time"] = str(time.time() - start)
    return response

CORS

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://myapp.com", "http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],   # GET, POST, PUT, DELETE, etc.
    allow_headers=["*"],
)
# For development only — do not use allow_origins=["*"] in production with credentials

Trusted Host / GZip / HTTPS redirect middleware

from fastapi.middleware.trustedhost import TrustedHostMiddleware
from fastapi.middleware.gzip import GZipMiddleware
from fastapi.middleware.httpsredirect import HTTPSRedirectMiddleware

app.add_middleware(TrustedHostMiddleware, allowed_hosts=["myapp.com", "*.myapp.com"])
app.add_middleware(GZipMiddleware, minimum_size=1000)
app.add_middleware(HTTPSRedirectMiddleware)  # redirect HTTP → HTTPS

Lifespan — startup and shutdown events

from contextlib import asynccontextmanager
from fastapi import FastAPI

ml_models = {}

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: load ML model, connect to DB, etc.
    ml_models["ner"] = load_model("ner-model")
    yield
    # Shutdown: cleanup
    ml_models.clear()

app = FastAPI(lifespan=lifespan)

Authentication & Security

FastAPI provides ready-made security utilities in fastapi.security. The recommended production pattern is OAuth2 Password flow + JWT tokens.

OAuth2 Password flow + JWT (production pattern)

pip install "python-jose[cryptography]" "passlib[bcrypt]"
from datetime import datetime, timedelta, timezone
from typing import Annotated
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from jose import JWTError, jwt
from passlib.context import CryptContext
from pydantic import BaseModel

SECRET_KEY = "change-me-in-production"   # use secrets.token_hex(32)
ALGORITHM  = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

app = FastAPI()

# ── Pydantic models ──────────────────────────────────────────────
class Token(BaseModel):
    access_token: str
    token_type: str

class TokenData(BaseModel):
    username: str | None = None

class User(BaseModel):
    username: str
    email: str | None = None
    disabled: bool | None = None

class UserInDB(User):
    hashed_password: str

# ── Password helpers ─────────────────────────────────────────────
def verify_password(plain: str, hashed: str) -> bool:
    return pwd_context.verify(plain, hashed)

def get_password_hash(password: str) -> str:
    return pwd_context.hash(password)

# ── JWT helpers ──────────────────────────────────────────────────
def create_access_token(data: dict, expires_delta: timedelta | None = None) -> str:
    to_encode = data.copy()
    expire = datetime.now(timezone.utc) + (expires_delta or timedelta(minutes=15))
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

# ── User lookup (replace with real DB query) ─────────────────────
fake_users_db = {
    "johndoe": {"username": "johndoe", "email": "john@example.com",
                "hashed_password": get_password_hash("secret"), "disabled": False},
}

def get_user(db: dict, username: str) -> UserInDB | None:
    if username in db:
        return UserInDB(**db[username])

def authenticate_user(db: dict, username: str, password: str) -> UserInDB | None:
    user = get_user(db, username)
    if not user or not verify_password(password, user.hashed_password):
        return None
    return user

# ── Current user dependency ──────────────────────────────────────
async def get_current_user(token: Annotated[str, Depends(oauth2_scheme)]) -> User:
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str = payload.get("sub")
        if username is None:
            raise credentials_exception
        token_data = TokenData(username=username)
    except JWTError:
        raise credentials_exception
    user = get_user(fake_users_db, token_data.username)
    if user is None:
        raise credentials_exception
    return user

async def get_current_active_user(
    current_user: Annotated[User, Depends(get_current_user)]
) -> User:
    if current_user.disabled:
        raise HTTPException(status_code=400, detail="Inactive user")
    return current_user

# ── Routes ───────────────────────────────────────────────────────
@app.post("/token", response_model=Token)
async def login(form_data: Annotated[OAuth2PasswordRequestForm, Depends()]):
    user = authenticate_user(fake_users_db, form_data.username, form_data.password)
    if not user:
        raise HTTPException(status_code=401, detail="Incorrect username or password",
                            headers={"WWW-Authenticate": "Bearer"})
    access_token = create_access_token(
        data={"sub": user.username},
        expires_delta=timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES),
    )
    return {"access_token": access_token, "token_type": "bearer"}

@app.get("/users/me", response_model=User)
async def read_users_me(current_user: Annotated[User, Depends(get_current_active_user)]):
    return current_user

API Key security

from fastapi.security import APIKeyHeader, APIKeyQuery, APIKeyCookie

api_key_header = APIKeyHeader(name="X-API-Key", auto_error=False)
api_key_query  = APIKeyQuery(name="api_key",  auto_error=False)

async def get_api_key(
    key_header: str | None = Depends(api_key_header),
    key_query:  str | None = Depends(api_key_query),
):
    if key_header == "secret" or key_query == "secret":
        return key_header or key_query
    raise HTTPException(status_code=403, detail="Invalid API Key")

@app.get("/secure/")
async def secure_route(api_key: str = Depends(get_api_key)):
    return {"message": "Access granted"}

HTTP Basic Auth

from fastapi.security import HTTPBasic, HTTPBasicCredentials
import secrets

security = HTTPBasic()

@app.get("/users/me")
def read_current_user(credentials: Annotated[HTTPBasicCredentials, Depends(security)]):
    correct_username = secrets.compare_digest(credentials.username.encode(), b"admin")
    correct_password = secrets.compare_digest(credentials.password.encode(), b"secret")
    if not (correct_username and correct_password):
        raise HTTPException(status_code=401, detail="Incorrect credentials",
                            headers={"WWW-Authenticate": "Basic"})
    return {"username": credentials.username}
Section 09

Background Tasks & SSE

Background tasks run after the response is sent — perfect for sending emails or writing logs without making the client wait. Server-Sent Events (SSE) stream real-time data over a persistent HTTP connection.

Background tasks

from fastapi import BackgroundTasks, FastAPI

app = FastAPI()

def write_notification(email: str, message: str = ""):
    with open("log.txt", "a") as f:
        f.write(f"Notification to {email}: {message}\n")

@app.post("/send-notification/{email}")
async def send_notification(email: str, background_tasks: BackgroundTasks):
    background_tasks.add_task(write_notification, email, message="Welcome!")
    return {"message": "Notification will be sent in the background"}

# Also works with dependencies
def get_query(background_tasks: BackgroundTasks, q: str | None = None):
    if q:
        background_tasks.add_task(write_log, f"Query: {q}")
    return q
BackgroundTasks vs Celery/ARQ BackgroundTasks runs in the same process — use it for lightweight fire-and-forget work (emails, logging). For heavy CPU tasks, retries, scheduling, or distributed queues use Celery, ARQ, or FastAPI's Taskiq integration instead.

Server-Sent Events (SSE)

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import asyncio

app = FastAPI()

async def event_stream(topic: str):
    """Yield SSE-formatted events."""
    count = 0
    while True:
        count += 1
        yield f"data: {{'topic': '{topic}', 'count': {count}}}\n\n"
        await asyncio.sleep(1)
        if count >= 10:     # stop after 10 events
            break

@app.get("/events/{topic}")
async def stream_events(topic: str):

FastAPI has built-in WebSocket support via Starlette. WebSockets provide full-duplex communication over a persistent connection — ideal for chat, live feeds, and collaborative tools.

Basic WebSocket endpoint

from fastapi import FastAPI, WebSocket
from fastapi.responses import HTMLResponse

app = FastAPI()

@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    while True:
        data = await websocket.receive_text()
        await websocket.send_text(f"You said: {data}")

Multi-client broadcast with ConnectionManager

from fastapi import WebSocket, WebSocketDisconnect

class ConnectionManager:
    def __init__(self):
        self.active_connections: list[WebSocket] = []

    async def connect(self, websocket: WebSocket):
        await websocket.accept()
        self.active_connections.append(websocket)

    def disconnect(self, websocket: WebSocket):
        self.active_connections.remove(websocket)

    async def send_personal(self, message: str, websocket: WebSocket):
        await websocket.send_text(message)

    async def broadcast(self, message: str):
        for connection in self.active_connections:
            await connection.send_text(message)

manager = ConnectionManager()

@app.websocket("/ws/{client_id}")
async def websocket_endpoint(websocket: WebSocket, client_id: int):
    await manager.connect(websocket)
    try:
        while True:
            data = await websocket.receive_text()
            await manager.send_personal(f"You: {data}", websocket)
            await manager.broadcast(f"#{client_id}: {data}")
    except WebSocketDisconnect:
        manager.disconnect(websocket)
        await manager.broadcast(f"#{client_id} left the chat")

WebSocket with dependencies and path params

from fastapi import Cookie, Query, WebSocketException, status

async def get_cookie_or_token(
    websocket: WebSocket,
    session: Annotated[str | None, Cookie()] = None,
    token: Annotated[str | None, Query()] = None,
):
    if session is None and token is None:
        raise WebSocketException(code=status.WS_1008_POLICY_VIOLATION)
    return session or token

@app.websocket("/items/{item_id}/ws")
async def ws_endpoint(
    websocket: WebSocket,
    item_id: str,
    auth: Annotated[str, Depends(get_cookie_or_token)],
):
    await websocket.accept()
    while True:
        data = await websocket.receive_text()
        await websocket.send_text(f"[{item_id}] {data}")

Project Structure with APIRouter

APIRouter is FastAPI's equivalent of Flask Blueprints. Split routes across multiple files, apply shared prefixes, tags, and dependencies at the router level, then include all routers in the main app.

Recommended file structure

app/
├── __init__.py
├── main.py           ← FastAPI instance + include_router calls
├── dependencies.py   ← shared dependencies (DB, auth tokens)
├── config.py         ← settings (pydantic-settings)
└── routers/
    ├── __init__.py
    ├── items.py      ← /items routes
    └── users.py      ← /users routes

app/dependencies.py

from typing import Annotated
from fastapi import Header, HTTPException

async def get_token_header(x_token: Annotated[str, Header()]):
    if x_token != "fake-super-secret-token":
        raise HTTPException(status_code=400, detail="X-Token header invalid")

async def get_query_token(token: str):
    if token != "jessica":
        raise HTTPException(status_code=400, detail="No Jessica token provided")

app/routers/items.py

from fastapi import APIRouter, Depends, HTTPException
from ..dependencies import get_token_header

router = APIRouter(
    prefix="/items",
    tags=["items"],
    dependencies=[Depends(get_token_header)],   # applies to ALL routes in this router
    responses={404: {"description": "Not found"}},
)

fake_items_db = {"plumbus": {"name": "Plumbus"}, "gun": {"name": "Portal Gun"}}

@router.get("/")
async def read_items():
    return fake_items_db

@router.get("/{item_id}")
async def read_item(item_id: str):
    if item_id not in fake_items_db:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"name": fake_items_db[item_id]["name"], "item_id": item_id}

@router.put("/{item_id}", tags=["custom"])   # override tag for one route
async def update_item(item_id: str):
    return {"item_id": item_id, "name": "The updated item"}

app/routers/users.py

from fastapi import APIRouter

router = APIRouter()

@router.get("/users/", tags=["users"])
async def read_users():
    return [{"username": "Rick"}, {"username": "Morty"}]

@router.get("/users/me", tags=["users"])
async def read_user_me():
    return {"username": "fakecurrentuser"}

@router.get("/users/{username}", tags=["users"])
async def read_user(username: str):
    return {"username": username}

app/main.py

from fastapi import Depends, FastAPI
from .dependencies import get_query_token
from .routers import items, users

app = FastAPI(dependencies=[Depends(get_query_token)])  # global dependency

app.include_router(users.router)
app.include_router(items.router)

# Include the same router with a different prefix (e.g. versioning)
app.include_router(
    items.router,
    prefix="/v2",
    tags=["items-v2"],
)

@app.get("/")
async def root():
    return {"message": "Hello Bigger Application!"}
Router configuration precedence Settings in include_router() override those in APIRouter(). Tags and dependencies accumulate — a route gets both the router-level tags and any extra tags from include_router. Responses merge. The prefix from include_router is prepended to the router's own prefix.

Settings & Configuration

Use pydantic-settings to manage environment variables and .env files with automatic type validation. Inject settings as a dependency for easy test overriding.

Install

config.py

from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    app_name: str = "My API"
    debug: bool = False
    admin_email: str              # required — must be set via env var
    database_url: str = "sqlite:///./app.db"
    secret_key: str               # required
    access_token_expire_minutes: int = 30

    model_config = SettingsConfigDict(
        env_file=".env",          # load from .env file
        env_file_encoding="utf-8",
        case_sensitive=False,     # APP_NAME and app_name are equivalent
    )

from functools import lru_cache
from typing import Annotated
from fastapi import Depends, FastAPI
from .config import Settings

app = FastAPI()

@lru_cache          # settings object created once, cached for app lifetime
def get_settings() -> Settings:
    return Settings()

@app.get("/info")
async def info(settings: Annotated[Settings, Depends(get_settings)]):
    return {
        "app_name": settings.app_name,
        "admin_email": settings.admin_email,
        "debug": settings.debug,
    }

Testing

FastAPI's TestClient (backed by httpx) lets you test routes synchronously without running a server. Use dependency_overrides to swap out DB or auth dependencies in tests.

Basic test setup

pip install httpx pytest
# main.py
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}

@app.get("/items/{item_id}")

    return {"item_id": item_id, "q": q}
# test_main.py
from fastapi.testclient import TestClient
from .main import app

client = TestClient(app)

def test_root():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"message": "Hello World"}

def test_read_item():
    response = client.get("/items/42?q=test")
    assert response.status_code == 200
    assert response.json() == {"item_id": 42, "q": "test"}

def test_invalid_item():
    response = client.get("/items/not-an-int")
    assert response.status_code == 422

def test_authenticated_route():
    # First, get a token
    response = client.post(
        "/token",
        data={"username": "johndoe", "password": "secret"},
