3. Higher-Order Components (HOC)

A function that takes a component and returns a new component with additional behaviour.

function withAuth(WrappedComponent) {
return function AuthComponent(props) {
const user = useAuth();
if (!user) return <Redirect to="/login" />;
return <WrappedComponent {...props} user={user} />;
};
}
const ProtectedDashboard = withAuth(Dashboard);
Modern Recommendation Prefer custom hooks over HOCs for new code. HOCs can cause prop collisions and are harder to trace in DevTools.

5.2 Error Boundaries

Error Boundaries catch JavaScript errors in the component tree and show a fallback UI. They ONLY work as class components.

class ErrorBoundary extends React.Component {
state = { hasError: false };
static getDerivedStateFromError(error) {
return { hasError: true };
}
componentDidCatch(error, errorInfo) {
logErrorToService(error, errorInfo);
}
render() {
if (this.state.hasError) return <h1>Something went wrong.</h1>;
return this.props.children;
}
}
Limitations Error boundaries do NOT catch: event handler errors (use try/catch), async code (promises, setTimeout), server-side rendering errors, or errors in the boundary itself.

5.3 Code Splitting with React.lazy & Suspense

const Dashboard = lazy(() => import("./Dashboard"));
function App() {
return (
<Suspense fallback={<div>Loading...</div>}>
<Routes>
<Route path="/dashboard" element={<Dashboard />} />
</Routes>
</Suspense>
);
}

Without splitting: one 500KB bundle loaded upfront. With splitting: a 100KB main bundle + lazy-loaded chunks only when the user navigates to that route.

5.4 Performance Optimization Checklist

Ordered by impact — fix architecture before reaching for memoization:

  • 1. Fix Architecture: Colocate state near where it’s used. Split frequently-updating components from static ones.
  • 2. Memoization (sparingly): React.memo for pure components, useMemo for expensive calculations, useCallback for stable callbacks.
  • 3. Virtualisation: Use react-window or @tanstack/virtual for long lists (render only visible items).
  • 4. Code Splitting: React.lazy + Suspense for route-level splitting. Dynamic import() for heavy libraries.
  • 5. Avoid Anti-Patterns: Don’t create objects/arrays inline in JSX. Don’t store derived data in state (compute during render). Avoid unnecessary useEffect chains.
