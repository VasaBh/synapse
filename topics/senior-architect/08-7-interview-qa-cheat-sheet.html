7. INTERVIEW Q&A CHEAT SHEET

QuestionKey Points in Answer
How do you handle distributed transactions?Saga pattern. Choreography (events) for simple flows; Orchestration (coordinator) for complex. Compensating transactions for rollback. Eventual consistency is accepted.
How would you implement zero-downtime deployment in OpenShift?Blue-green via route switching, or rolling update with PodDisruptionBudget. Readiness probes ensure traffic only goes to ready pods. Health check gates before route flip.
HPA vs VPA — when to use each?HPA for stateless/web services (add replicas). VPA for stateful/memory-bound (tune resources). Never run both on same CPU metric. Use KEDA for event-driven scale-to-zero.
How would you secure an MCP server in production?OAuth2 auth, tool-level RBAC, input validation against JSON Schema, rate limiting, audit logging, sandboxed execution, human-in-the-loop for destructive tools.
How do you prevent an agent from looping or taking harmful actions?Max iteration limit, timeout on every tool call, human checkpoints before irreversible actions, prefer reversible actions, scope-limited tool set, audit trail.
Design a system for 1M concurrent users.CDN at edge, API Gateway, horizontally scaled stateless services (HPA), async processing via Kafka, read replicas + caching (Redis), observability stack, multi-region failover.
How do you migrate a monolith to microservices?Strangler Fig pattern. Identify bounded contexts first. Extract high-value / high-change areas first. Use an anti-corruption layer. Run in parallel; dark-launch; feature flags.
What is the CAP theorem and how does it affect your design?Can guarantee only 2 of: Consistency, Availability, Partition Tolerance. Distributed systems must tolerate partitions. Choose CP (banking) or AP (social feeds) based on business need.
How do you handle observability in microservices?Three pillars: Logs (ELK), Metrics (Prometheus+Grafana), Traces (OpenTelemetry+Jaeger). Correlation IDs propagated across all services. Alert on SLOs not just raw metrics.
Explain OpenShift Route TLS modes.Edge: TLS terminates at router, plain HTTP to pod. Passthrough: TLS goes all the way to pod. Re-encrypt: router terminates and re-encrypts. Choose Re-encrypt for highest security.

Final Preparation Tips

  • Prepare 2–3 past projects with architectural decisions using STAR format (Situation, Task, Action, Result)
  • Be ready to whiteboard: draw sequence diagrams, deployment diagrams, data flow
  • Every answer: state the trade-off. 'This approach gives us X but costs us Y, which is acceptable because...'
  • For OpenShift questions: know oc commands and be comfortable discussing operator model
  • For AI/MCP questions: understand you are talking about emerging technology — show awareness of limitations and risks, not just capabilities
  • Read: OpenShift docs, Anthropic MCP spec (modelcontextprotocol.io), 12factor.net, Martin Fowler's microservices articles
