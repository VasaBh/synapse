LLM Tool Use Fundamentals

Full Tool Calling Example (OpenAI)

from openai import OpenAI
import json

client = OpenAI()

tools = [{
    "type": "function",
    "function": {
        "name": "get_stock_price",
        "description": "Get the current stock price for a given ticker symbol.",
        "parameters": {
            "type": "object",
            "properties": {
                "ticker": {"type": "string", "description": "Stock ticker, e.g. AAPL"},
                "currency": {"type": "string", "enum": ["USD", "GBP", "EUR"], "default": "USD"}
            },
            "required": ["ticker"]
        }
    }
}]

messages = [{"role": "user", "content": "What is Apple's stock price?"}]

# First call — model decides to use a tool
response = client.chat.completions.create(
    model="gpt-4o-mini", tools=tools, tool_choice="auto", messages=messages
)
tool_call = response.choices[0].message.tool_calls[0]
args = json.loads(tool_call.function.arguments)  # {"ticker": "AAPL"}

# Execute the tool
result = {"price": 213.45, "currency": "USD"}

# Second call — submit result
messages += [
    response.choices[0].message,  # assistant message with tool_calls
    {"role": "tool", "tool_call_id": tool_call.id, "content": json.dumps(result)}
]
final = client.chat.completions.create(model="gpt-4o-mini", messages=messages)
print(final.choices[0].message.content)
Tool descriptions are part of your prompt The quality of your tool's description field directly determines how accurately the model selects and invokes it. Write descriptions as if explaining to a junior developer which function to call and when.
Section 02

Tool Design Patterns

Good tool design is as important as good prompt design. Poorly named, vague, or overlapping tools cause the model to select the wrong tool, pass wrong arguments, or fail silently.

Atomic Tools

One tool, one responsibility. search_documents not search_and_summarise_documents. Compose in application code.

Read vs Write

Separate read tools (no side effects) from write tools (create/update/delete). Annotate clearly in descriptions.

Idempotent Writes

Write tools should be safe to call twice. Accept an optional idempotency_key for critical operations.

Rich Error Messages

Return structured errors: {"error": "not_found", "message": "...", "suggestion": "..."}. Models use these to self-correct.

Well-Designed Tool Definition

search_tool = {
    "type": "function",

MCP is an open standard (created by Anthropic, Nov 2024) for connecting AI models to external tools and data sources. It standardises the interface between AI hosts (Claude, Cursor, VS Code) and MCP servers (tools, databases, APIs) using JSON-RPC 2.0.

Section 04

Building MCP Servers (Python)

The mcp Python SDK (by Anthropic) provides a decorator-based API for exposing tools, resources, and prompts. A minimal server is under 30 lines of code.

from mcp.server.fastmcp import FastMCP
import httpx

mcp = FastMCP("Weather Service")

@mcp.tool()
async def get_weather(city: str, units: str = "celsius") -> dict:
    """Get current weather for a city. Units: celsius or fahrenheit."""
    async with httpx.AsyncClient() as client:
        r = await client.get(
            "https://wttr.in/{city}",
            params={"format": "j1"},
        )
        data = r.json()
        temp = data["current_condition"][0]["temp_C"]
        if units == "fahrenheit":
            temp = int(temp) * 9 // 5 + 32
        return {"city": city, "temperature": temp, "units": units}

@mcp.resource("weather://forecast/{city}")
async def weather_forecast(city: str) -> str:
    """3-day forecast resource for a city."""
    return f"Forecast data for {city}..."

@mcp.prompt()
def weather_report_prompt(city: str) -> str:
    """Generate a weather report prompt template."""
    return f"Write a friendly weather report for {city} based on the current conditions."

if __name__ == "__main__":
    mcp.run()  # stdio transport (default)

Section 05

Building MCP Servers (TypeScript)

The TypeScript SDK is the reference implementation — most official Anthropic MCP servers are written in TypeScript. It provides full type safety and is the best choice for production servers.

import { McpServer, ResourceTemplate } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";

const server = new McpServer({ name: "todo-server", version: "1.0.0" });
const todos: { id: number; text: string; done: boolean }[] = [];

// Tool: add a todo
server.tool(
  "add_todo",
  "Add a new todo item to the list",
  { text: z.string().describe("The todo item text") },
  async ({ text }) => {
    const todo = { id: todos.length + 1, text, done: false };
    todos.push(todo);
    return { content: [{ type: "text", text: `Added todo #${todo.id}: ${text}` }] };
  }
);

// Tool: list todos
server.tool("list_todos", "List all todo items", {}, async () => {
  const list = todos.map(t => `${t.done ? "✓" : "○"} #${t.id}: ${t.text}`).join("\n");
  return { content: [{ type: "text", text: list || "No todos yet." }] };
});

// Resource: expose todos as a resource
server.resource(
  "todos://all",
  new ResourceTemplate("todos://all", { list: undefined }),
  async () => ({
    contents: [{ uri: "todos://all", text: JSON.stringify(todos, null, 2), mimeType: "application/json" }]
  })
);

// Start server
const transport = new StdioServerTransport();
await server.connect(transport);
Use Zod for input schemas The TypeScript SDK accepts Zod schemas for tool parameters. Zod provides runtime validation + auto-generated JSON Schema — the best of both worlds.

Parallel Tool Calls

Modern LLMs can request multiple tool calls in a single response. Your application should execute them concurrently with asyncio.gather, then return all results in a single follow-up message.

LLM Response3 tool_calls in one turn
asyncio.gather() — all 3 in parallel
get_stock"AAPL"
get_stock"MSFT"
get_weather"London"
~100ms total vs ~300ms sequential
Submit All Resultsin one follow-up message
LLM Final Answer
import asyncio
import json
from openai import AsyncOpenAI

client = AsyncOpenAI()

async def execute_tool(tool_call) -> dict:
    name = tool_call.function.name
    args = json.loads(tool_call.function.arguments)
    # Route to actual tool implementation
    if name == "get_stock_price":
        return {"price": 213.45, "ticker": args["ticker"]}
    if name == "get_weather":
        return {"temp": 18, "city": args["city"], "condition": "Cloudy"}
    return {"error": f"Unknown tool: {name}"}

async def handle_parallel_tools(messages: list) -> str:
    response = await client.chat.completions.create(
        model="gpt-4o-mini", tools=tools, tool_choice="auto", messages=messages
    )
    msg = response.choices[0].message

    if not msg.tool_calls:
        return msg.content

    # Execute all tool calls in parallel
    results = await asyncio.gather(*[execute_tool(tc) for tc in msg.tool_calls])

    # Submit all results at once
    messages.append(msg)
    for tc, result in zip(msg.tool_calls, results):
        messages.append({
            "role": "tool",
            "tool_call_id": tc.id,
            "content": json.dumps(result)
        })

    final = await client.chat.completions.create(model="gpt-4o-mini", messages=messages)
    return final.choices[0].message.content
Claude makes sequential calls by default OpenAI models tend to batch parallel tool calls in one response; Claude often makes sequential calls. Test both. For Claude, you may need to explicitly instruct it to gather multiple pieces of information simultaneously.
Section 08

Tool Security

Tools that interact with external systems introduce attack surface. The three main threats are prompt injection (malicious content in tool results), tool abuse (LLM calling dangerous tools unexpectedly), and data exfiltration via tool outputs.

from functools import wraps
import logging

ALLOWED_TOOLS = {"search_documents", "get_weather", "calculate"}
DANGEROUS_TOOLS = {"delete_records", "send_email", "execute_code"}

def require_confirmation(tool_name: str) -> bool:
    """Prompt user before executing high-risk tools."""
    if tool_name in DANGEROUS_TOOLS:
        answer = input(f"⚠️  Allow tool '{tool_name}'? [y/N]: ")
        return answer.lower() == "y"
    return True

def sanitise_tool_result(result: str) -> str:
    """Strip injection attempts from tool results."""
    injection_patterns = [
        "ignore previous instructions",
        "system prompt:",
        "new instructions:",
    ]
    lowered = result.lower()
    for pattern in injection_patterns:
        if pattern in lowered:
            logging.warning(f"Potential prompt injection detected in tool result")
            return "[Tool result redacted due to security policy]"
    return result
Never pass unsanitised LLM outputs to shell tools If you have a run_shell_command tool, the LLM could be tricked into running arbitrary commands via a crafted document. Always sandbox code execution in Docker or a language-level sandbox (e.g., RestrictedPython).

Wrapping MCP Tools in LangChain

from langchain_core.tools import StructuredTool
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def create_langchain_mcp_tools(server_script: str) -> list:
    """Wrap all tools from an MCP server as LangChain StructuredTools."""
    server_params = StdioServerParameters(command="python", args=[server_script])

    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            mcp_tools = await session.list_tools()

            lc_tools = []
            for tool in mcp_tools.tools:
                async def call_tool(name=tool.name, **kwargs):
                    async with stdio_client(server_params) as (r, w):
                        async with ClientSession(r, w) as s:
                            await s.initialize()
                            result = await s.call_tool(name, arguments=kwargs)
                            return result.content[0].text

                lc_tools.append(StructuredTool(
                    name=tool.name,
                    description=tool.description,
                    func=call_tool,
                    coroutine=call_tool,
                ))
    return lc_tools

Dynamic Tool Registration

Discover available MCP servers at runtime. Register only the tools relevant to the current task context.

Tool Retrieval with RAG

With 100+ tools, embed tool descriptions. At query time, retrieve the top-K relevant tools to pass to the LLM — avoids token bloat.

Graceful Degradation

Catch tool execution errors and return structured error messages. The LLM can self-correct or inform the user rather than crashing.

Audit Logging

Log every tool call: timestamp, tool name, arguments, result, latency. Essential for debugging multi-step agent traces.

MCPServerStdio is the client-side class from the OpenAI Agents Python SDK (openai-agents) for launching a local MCP server as a subprocess and connecting to it over stdin/stdout. It handles the full lifecycle: spawning the process, performing the MCP handshake, listing available tools, and tearing down cleanly. Agents receive the server's tools automatically — no manual tool registration needed.

PropertyDescription
params.commandThe executable to run — e.g. "python", "node", "npx"
params.argsList of arguments passed to the command — e.g. ["server.py"]
params.envOptional dict of environment variables injected into the server process
nameOptional human-readable label for the server (appears in traces)
cache_tools_listCache the tool list after first fetch — avoids a round-trip on every agent run (default False)

Example: Basic Usage with OpenAI Agents SDK

import asyncio
from agents import Agent, Runner
from agents.mcp import MCPServerStdio

async def main():
    # 1. Define the MCP server — points to a local Python MCP server script
    mcp_server = MCPServerStdio(
        name="weather-service",
        params={
            "command": "python",
            "args": ["weather_server.py"],      # the FastMCP server from Section 4
            "env": {"WEATHER_API_KEY": "sk-..."},
        },
        cache_tools_list=True,   # avoid re-fetching tool list on every run
    )

    # 2. Create an agent — mcp_servers wires tools in automatically
    agent = Agent(
        name="Weather Agent",
        instructions="You help users with weather queries. Use available tools.",
        mcp_servers=[mcp_server],
    )

    # 3. Run inside the server's async context manager (handles process lifecycle)
    async with mcp_server:
        result = await Runner.run(agent, "What's the weather in Paris right now?")
        print(result.final_output)

asyncio.run(main())

Example: Connecting to Multiple MCP Servers

from agents import Agent, Runner
from agents.mcp import MCPServerStdio

weather_server = MCPServerStdio(
    name="weather",
    params={"command": "python", "args": ["weather_server.py"]},
)
database_server = MCPServerStdio(
    name="database",
    params={"command": "python", "args": ["db_server.py"],
            "env": {"DB_URL": "postgresql://localhost/mydb"}},
)
search_server = MCPServerStdio(
    name="search",
    params={"command": "npx", "args": ["-y", "@modelcontextprotocol/server-brave-search"],
            "env": {"BRAVE_API_KEY": "your-key"}},
)

agent = Agent(
    name="Research Agent",
    instructions="Research topics using weather, database, and web search tools.",
    mcp_servers=[weather_server, database_server, search_server],
)

# Use asynccontextmanager to open all servers together
from contextlib import AsyncExitStack

async def run():
    async with AsyncExitStack() as stack:
        for server in [weather_server, database_server, search_server]:
            await stack.enter_async_context(server)
        result = await Runner.run(agent, "Find data on climate trends in Paris")
        print(result.final_output)

Example: Listing Available Tools from an MCP Server

from agents.mcp import MCPServerStdio

async def inspect_server_tools(script_path: str):
    """Print all tools exposed by an MCP server."""
    server = MCPServerStdio(
        params={"command": "python", "args": [script_path]}
    )
    async with server:
        tools = await server.list_tools()
        for tool in tools:
            print(f"  {tool.name}: {tool.description}")
            if tool.inputSchema.get("properties"):
                for param, schema in tool.inputSchema["properties"].items():
                    required = param in tool.inputSchema.get("required", [])
                    print(f"    - {param} ({schema.get('type','any')}){'*' if required else ''}")

# Run it
import asyncio
asyncio.run(inspect_server_tools("weather_server.py"))

# Output:
#   get_weather: Get current weather for a city. Units: celsius or fahrenheit.
#     - city (string)*
#     - units (string)

LSEG Official MCP Server

LSEG launched its managed MCP server in October 2025 in partnership with Microsoft, and extended it to OpenAI in December 2025 and Databricks in 2026. It is a hosted remote server (SSE transport) — LSEG runs the infrastructure and you connect with your existing Workspace/Financial Analytics credentials. There is no self-hosted package to install.

Microsoft Copilot Studio / M365

Connect directly in Copilot Studio — LSEG's MCP server appears as a connectable data source. Requires an active LSEG Financial Analytics subscription linked to your Microsoft tenant.

lseg.com — Microsoft announcement

OpenAI ChatGPT Enterprise

LSEG's MCP connector went live in ChatGPT from December 2025 for OpenAI enterprise customers — financial data accessible directly inside ChatGPT agents.

lseg.com — OpenAI announcement

Databricks Marketplace

Available in the Databricks Marketplace for use with Agent Bricks (Databricks' agentic AI product). Provides real-time connectivity to LSEG financial intelligence inside Databricks workflows.

lseg.com — Databricks announcement

Claude / Custom agents (SSE)

For custom agent code, LSEG exposes an SSE endpoint. Connect using MCPServerSse from the OpenAI Agents SDK with your LSEG API key. Also see the LSEG Claude Plugin sample on GitHub.

Refinitiv (LSEG Data Library) and Bloomberg (BLPAPI) are enterprise financial data platforms. The custom FastMCP servers below are for teams who need finer control over tool definitions, or who cannot use the hosted/community options above. Neither has a public MCP server on the marketplaces — both require proprietary credentials, internal network access, and licensed client software. The pattern is to wrap their Python SDKs as a custom FastMCP server and connect via MCPServerStdio.

Prerequisites Refinitiv requires a valid LSEG Workspace / Eikon session running on the same machine (pip install refinitiv-data). Bloomberg requires Bloomberg Terminal + BLPAPI running locally (pip install blpapi from the Bloomberg SDK). Neither is available without an enterprise licence.

Refinitiv (LSEG) MCP Server

# pip install "mcp[cli]" refinitiv-data pandas
# refinitiv_mcp_server.py

from mcp.server.fastmcp import FastMCP
import refinitiv.data as rd
import pandas as pd

mcp = FastMCP("Refinitiv Data Service")

@mcp.tool()
async def get_price_history(
    ric: str,
    start: str,
    end: str,
    fields: list[str] = ["TR.PriceClose", "TR.Volume"],
) -> dict:
    """
    Fetch historical price data for a RIC (Reuters Instrument Code).
    Args:
        ric:    e.g. "AAPL.O", "VOD.L", ".SPX"
        start:  ISO date string, e.g. "2024-01-01"
        end:    ISO date string, e.g. "2024-12-31"
        fields: Refinitiv field names (TR.* or standard)
    """
    rd.open_session()
    df = rd.get_data(ric, fields=fields, parameters={"SDate": start, "EDate": end})
    rd.close_session()
    return df.to_dict(orient="records")

@mcp.tool()
async def get_realtime_quote(ric: str) -> dict:
    """Get live bid/ask/last price for a RIC from Refinitiv Workspace."""
    rd.open_session()
    df = rd.get_data(
        ric,
        fields=["TR.PriceBid", "TR.PriceAsk", "TR.PriceLast",
                "TR.Volume", "TR.PriceChangePercent"]
    )
    rd.close_session()
    return df.to_dict(orient="records")[0]

@mcp.tool()
async def search_instruments(query: str, asset_class: str = "Equity") -> list[dict]:
    """Search for instruments by name or keyword. asset_class: Equity, Bond, FX, Commodity."""
    rd.open_session()
    results = rd.discovery.search(
        query=query,
        filter=f"AssetClass eq '{asset_class}'",
        top=10,
        select="DocumentTitle,RIC,AssetClass,ExchangeName",
    )
    rd.close_session()
    return results.to_dict(orient="records")

@mcp.tool()
async def get_fundamentals(ric: str) -> dict:
    """Retrieve key fundamental data: P/E, market cap, revenue, EPS for a stock."""
    rd.open_session()
    df = rd.get_data(ric, fields=[
        "TR.CompanyMarketCap", "TR.PERatio", "TR.Revenue",
        "TR.EPSActual", "TR.DividendYield", "TR.CompanyName",
    ])
    rd.close_session()
    return df.to_dict(orient="records")[0]

if __name__ == "__main__":
    mcp.run()  # stdio transport

Bloomberg BLPAPI MCP Server

# pip install "mcp[cli]" blpapi pandas
# bloomberg_mcp_server.py
# Requires Bloomberg Terminal running + BLPAPI session on localhost:8194

from mcp.server.fastmcp import FastMCP
import blpapi
import pandas as pd
from datetime import datetime

mcp = FastMCP("Bloomberg Data Service")

BLPAPI_HOST = "localhost"
BLPAPI_PORT = 8194

def _open_session() -> blpapi.Session:
    opts = blpapi.SessionOptions()
    opts.setServerHost(BLPAPI_HOST)
    opts.setServerPort(BLPAPI_PORT)
    session = blpapi.Session(opts)
    if not session.start():
        raise RuntimeError("Bloomberg session failed to start — is Terminal running?")
    if not session.openService("//blp/refdata"):
        raise RuntimeError("Failed to open Bloomberg //blp/refdata service")
    return session

@mcp.tool()
async def get_reference_data(
    securities: list[str],
    fields: list[str],
) -> list[dict]:
    """
    Fetch Bloomberg reference (snap) data for one or more securities.
    Args:
        securities: Bloomberg tickers, e.g. ["AAPL US Equity", "MSFT US Equity"]
        fields:     Bloomberg field mnemonics, e.g. ["PX_LAST", "VOLUME", "PE_RATIO"]
    """
    session = _open_session()
    refdata = session.getService("//blp/refdata")
    request = refdata.createRequest("ReferenceDataRequest")
    for s in securities:
        request.getElement("securities").appendValue(s)
    for f in fields:
        request.getElement("fields").appendValue(f)

    session.sendRequest(request)
    rows = []
    while True:
        event = session.nextEvent(500)
        for msg in event:
            if msg.messageType() == blpapi.Name("ReferenceDataResponse"):
                for sec in msg.getElement("securityData"):
                    row = {"security": sec.getElementAsString("security")}
                    fld_data = sec.getElement("fieldData")
                    for f in fields:
                        try:
                            row[f] = fld_data.getElementAsFloat(f)
                        except Exception:
                            row[f] = None
                    rows.append(row)
        if event.eventType() == blpapi.Event.RESPONSE:
            break
    session.stop()
    return rows

@mcp.tool()
async def get_historical_data(
    security: str,
    fields: list[str],
    start_date: str,
    end_date: str,
    periodicity: str = "DAILY",
) -> list[dict]:
    """
    Fetch Bloomberg historical data for a single security.
    Args:
        security:    e.g. "SPX Index", "AAPL US Equity"
        fields:      e.g. ["PX_LAST", "VOLUME"]
        start_date:  "YYYYMMDD"
        end_date:    "YYYYMMDD"
        periodicity: DAILY | WEEKLY | MONTHLY | QUARTERLY | YEARLY
    """
    session = _open_session()
    refdata = session.getService("//blp/refdata")
    request = refdata.createRequest("HistoricalDataRequest")
    request.getElement("securities").appendValue(security)
    for f in fields:
        request.getElement("fields").appendValue(f)
    request.set("startDate", start_date)
    request.set("endDate", end_date)
    request.set("periodicitySelection", periodicity)

    session.sendRequest(request)
    rows = []
    while True:
        event = session.nextEvent(500)
        for msg in event:
            if msg.messageType() == blpapi.Name("HistoricalDataResponse"):
                field_data_array = (msg.getElement("securityData")
                                       .getElement("fieldData"))
                for i in range(field_data_array.numValues()):
                    item = field_data_array.getValue(i)
                    row = {"date": str(item.getElementAsDatetime("date").date())}
                    for f in fields:
                        try:
                            row[f] = item.getElementAsFloat(f)
                        except Exception:
                            row[f] = None
                    rows.append(row)
        if event.eventType() == blpapi.Event.RESPONSE:
            break
    session.stop()
    return rows

@mcp.tool()
async def get_intraday_bar(
    security: str,
    event_type: str = "TRADE",
    interval_minutes: int = 5,
    start_datetime: str = "",
    end_datetime: str = "",
) -> list[dict]:
    """
    Fetch intraday bar data from Bloomberg.
    Args:
        security:         e.g. "AAPL US Equity"
        event_type:       TRADE | BID | ASK | BID_BEST | ASK_BEST
        interval_minutes: bar interval in minutes (1–1440)
        start_datetime:   "YYYY-MM-DDTHH:MM:SS" UTC
        end_datetime:     "YYYY-MM-DDTHH:MM:SS" UTC
    """
    session = _open_session()
    refdata = session.getService("//blp/refdata")
    request = refdata.createRequest("IntradayBarRequest")
    request.set("security", security)
    request.set("eventType", event_type)
    request.set("interval", interval_minutes)
    if start_datetime:
        request.set("startDateTime", start_datetime)
    if end_datetime:
        request.set("endDateTime", end_datetime)

    session.sendRequest(request)
    rows = []
    while True:
        event = session.nextEvent(500)
        for msg in event:
            if msg.messageType() == blpapi.Name("IntradayBarResponse"):
                bar_data = msg.getElement("barData").getElement("barTickData")
                for i in range(bar_data.numValues()):
                    bar = bar_data.getValue(i)
                    rows.append({
                        "time":   str(bar.getElementAsDatetime("time")),
                        "open":   bar.getElementAsFloat("open"),
                        "high":   bar.getElementAsFloat("high"),
                        "low":    bar.getElementAsFloat("low"),
                        "close":  bar.getElementAsFloat("close"),
                        "volume": bar.getElementAsInteger("volume"),
                    })
        if event.eventType() == blpapi.Event.RESPONSE:
            break
    session.stop()
    return rows

if __name__ == "__main__":
    mcp.run()
