8. map, reduce & Functional Programming

Python supports functional programming patterns through built-in functions and the functools/itertools modules.

8.1 map, filter, reduce

# map — apply function to each element
names = ['alice', 'bob', 'charlie']
upper_names = list(map(str.upper, names))  # ['ALICE', 'BOB', 'CHARLIE']
# filter — keep elements where function returns True
evens = list(filter(lambda x: x % 2 == 0, range(10)))
# reduce — fold/accumulate to single value
from functools import reduce
product = reduce(lambda a, b: a * b, [1, 2, 3, 4, 5])  # 120
# Prefer comprehensions for readability
upper_names = [n.upper() for n in names]     # clearer than map
evens = [x for x in range(10) if x % 2 == 0]  # clearer than filter

8.3 functools Highlights

from functools import partial, reduce, lru_cache, singledispatch
# partial — fix some arguments
int_from_hex = partial(int, base=16)
int_from_hex('ff')  # 255
# singledispatch — function overloading
@singledispatch
def process(data):
raise TypeError(f'Unsupported: {type(data)}')
@process.register(str)
def _(data): return data.upper()
@process.register(list)
def _(data): return [process(x) for x in data]
