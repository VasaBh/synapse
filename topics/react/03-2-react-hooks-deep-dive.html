2. React Hooks (Deep Dive)

2.1 useState — State Management

const [state, setState] = useState(initialValue);

Key Behaviours

Functional update: When new state depends on old state, use setState(prev => prev + 1)
Lazy initialization: Pass a function to useState for expensive initial computations: useState(() => computeExpensiveValue())
  • Batching: Multiple setState calls in the same event handler are batched into a single re-render.
⚠️ Objects & Arrays — Always Create New References user.name = “Bob”; setUser(user) won’t trigger a re-render. Use setUser({ ...user, name: “Bob” }) to create a new object.

2.2 useEffect — Side Effects

useEffect(() => {
// EFFECT runs after render
return () => { /* CLEANUP before next effect or unmount */ };
}, [dependencies]);

Dependency Array Controls When It Runs

DependencyBehaviour
useEffect(() => { ... })Runs after EVERY render (usually wrong)
useEffect(() => { ... }, [])Runs ONCE on mount only
useEffect(() => { ... }, [id])Runs when ‘id’ changes

Real-World Example: API Fetch with Cleanup

useEffect(() => {
let cancelled = false;
async function fetchUser() {
const res = await fetch(`/api/users/${id}`);
const data = await res.json();
if (!cancelled) setUser(data);
}
fetchUser();
return () => { cancelled = true; }; // Prevent race conditions
}, [id]);

2.3 useRef — Persistent Mutable Value

useRef holds a mutable value that does NOT cause re-renders when changed. Two main uses:

  • DOM Access: Get a reference to a DOM element (e.g., focus an input).
  • Persist values: Store interval IDs, previous values, or any mutable value across renders without triggering re-render.
function TextInput() {
const inputRef = useRef(null);
const focusInput = () => inputRef.current.focus();
return <input ref={inputRef} />;
}

2.4 useMemo & useCallback — Performance

useMemo caches a computed VALUE. useCallback caches a FUNCTION reference.

// useMemo — expensive computation runs only when 'items' changes
const sortedList = useMemo(() => {
return items.sort((a, b) => a.price - b.price);
}, [items]);
// useCallback — stable function reference for memoized children
const handleSubmit = useCallback((data) => {
submitForm(data);
}, [submitForm]);
When to Use (and When NOT to) ✅ Use when: passing callbacks to React.memo children, expensive computations, stable refs for useEffect deps. ❌ Don’t use for: simple calculations, inline handlers — premature optimization adds complexity.

2.5 useContext — Avoiding Prop Drilling

Context provides data to deeply nested components without passing props through every level.

// 1. Create: const ThemeContext = React.createContext("light");
// 2. Provide at top level:
<ThemeContext.Provider value={{ theme, setTheme }}>
<Header />
</ThemeContext.Provider>
// 3. Consume anywhere below:
const { theme, setTheme } = useContext(ThemeContext);
⚠️ Performance Warning When context value changes, ALL consumers re-render. For frequently changing values (e.g., mouse position), use state management libraries instead.

2.6 Custom Hooks — Reusable Logic

Custom hooks extract reusable stateful logic. They always start with use.
function useLocalStorage(key, initialValue) {
const [value, setValue] = useState(() => {
const stored = localStorage.getItem(key);
return stored ? JSON.parse(stored) : initialValue;
});
useEffect(() => {
localStorage.setItem(key, JSON.stringify(value));
}, [key, value]);
return [value, setValue];
}
// Usage — works just like useState:
const [theme, setTheme] = useLocalStorage("theme", "dark");
