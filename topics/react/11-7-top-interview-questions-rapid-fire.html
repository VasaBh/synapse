7. Top Interview Questions — Rapid Fire

Q1: What is the difference between controlled and uncontrolled components?

Controlled: React state drives the input value via value + onChange. Uncontrolled: the DOM holds the value, accessed via ref.

Q2: What is React.StrictMode?

A development-only wrapper that calls components twice to catch side effects, warns about deprecated APIs, and helps find bugs early. No effect in production.

Q3: What is prop drilling and how to solve it?

Passing props through many levels of components that don’t need them. Solutions: Context API, state management libraries (Zustand/Redux), component composition.

Q4: What is hydration?

After SSR sends HTML to the browser, React “hydrates” it — attaches event listeners and state to the existing HTML. Mismatch between server and client HTML = hydration error.

Q5: Explain the useEffect cleanup function.

Runs before the next effect execution and on unmount. Used to cancel API requests, remove event listeners, clear timers, and close WebSocket connections.

Q6: What are React Server Components?

Components that run ONLY on the server. They can access databases directly, have zero client-side JS bundle cost, and cannot use state or effects. Introduced in Next.js 13 App Router.

Q7: useState vs useReducer?

useState: simple state (toggle, counter, single value). useReducer: complex state logic, multiple sub-values, when next state depends on previous. Similar to Redux pattern.

Q8: What is the React Compiler (React Forget)?

An experimental compiler that auto-memoises components and hooks, making React.memo, useMemo, and useCallback unnecessary. Being tested in Meta’s production apps.

Q9: What is a key in React and why is it important?

A special string attribute used during list rendering. It helps React identify which items changed, were added, or removed. Without stable keys, React re-renders the entire list and can introduce bugs with component state.

Q10: What is the difference between useLayoutEffect and useEffect?

useLayoutEffect fires synchronously after DOM mutations but BEFORE the browser paints. useEffect fires after paint. Use useLayoutEffect for DOM measurements to prevent visual flicker.
