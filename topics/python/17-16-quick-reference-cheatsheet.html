16. Quick Reference Cheatsheet

ConceptKey Points
Comprehensions[expr for x in iter if cond] — list, dict, set, generator variants
Walrus :=Assign in expression: if (n := len(x)) > 10: use(n)
match/caseStructural pattern matching with destructuring (3.10+)
Decorators@deco = func = deco(func). Use @wraps. Stack: bottom wraps first.
Generatorsyield suspends state. Memory O(1). yield from delegates. send() injects.
async/awaitCooperative concurrency. asyncio.gather for parallel I/O. Single thread.
Context Managerwith: __enter__/__exit__. @contextmanager for generator-based.
Async CMasync with: __aenter__/__aexit__. @asynccontextmanager.
Async Generatorsasync def + yield. async for to consume. aclose() for cleanup.
map/filter/reduceFunctional tools. Prefer comprehensions. itertools for advanced.
Dunder Methods__init__, __repr__, __add__, __iter__, __getitem__, __call__, ...
Duck TypingCheck behavior, not type. Protocol for structural typing.
Metaclassestype subclass. __init_subclass__ is simpler. Descriptors for attributes.
Testingpytest + fixtures + parametrize + mock. anyio for async tests.
GIL1 thread runs bytecode. asyncio for I/O. multiprocessing for CPU. 3.13+ no-GIL.
