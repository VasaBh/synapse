1. Advanced Language Features

Python offers powerful features beyond the basics that enable expressive, concise, and high-performance code. This chapter covers the most important advanced constructs.

1.1 Comprehensions

# List comprehension
squares = [x**2 for x in range(10) if x % 2 == 0]
# Dict comprehension
word_lengths = {w: len(w) for w in ['hello', 'world', 'python']}
# Set comprehension
unique_lengths = {len(w) for w in words}
# Nested comprehension (matrix flatten)
flat = [x for row in matrix for x in row]
# Generator expression (lazy, memory-efficient)
total = sum(x**2 for x in range(1_000_000))  # no list created

1.2 Unpacking & Starred Expressions

# Extended unpacking
first, *middle, last = [1, 2, 3, 4, 5]  # middle = [2, 3, 4]
# Dict merging (Python 3.9+)
merged = {**defaults, **user_config}  # user_config overrides
merged = defaults | user_config       # same, cleaner
# Function argument unpacking
def greet(name, age): ...
data = {'name': 'Alice', 'age': 30}
greet(**data)  # equivalent to greet(name='Alice', age=30)

1.3 Walrus Operator (:=)

The walrus operator assigns a value to a variable as part of an expression (Python 3.8+).

# Avoid calling expensive function twice
if (n := len(data)) > 100:
print(f'Too long: {n} items')
# In while loops
while chunk := file.read(8192):
process(chunk)
# In list comprehensions
results = [y for x in data if (y := transform(x)) is not None]

1.4 Structural Pattern Matching (match/case)

Python 3.10+ introduced match/case for powerful pattern matching with destructuring.

match command:
case {'action': 'buy', 'item': item, 'qty': int(qty)}:
buy(item, qty)
case {'action': 'sell', 'item': item}:
sell(item)
case {'action': action}:
print(f'Unknown action: {action}')
# With guards
match point:
case Point(x, y) if x == y:
print('On diagonal')
case Point(x, y):
print(f'({x}, {y})')

1.5 Slots, Dataclasses & NamedTuples

from dataclasses import dataclass, field
@dataclass(frozen=True, slots=True)  # immutable + memory-efficient
class Point:
x: float
y: float
label: str = 'origin'
tags: list[str] = field(default_factory=list)
@property
def distance(self) -> float:
return (self.x**2 + self.y**2) ** 0.5
# NamedTuple (lighter alternative)
from typing import NamedTuple
class Color(NamedTuple):
r: int
g: int
b: int
slots=True Adding slots=True to dataclasses (Python 3.10+) uses __slots__ instead of __dict__, reducing memory by 30-40% per instance and speeding up attribute access.
