3. Vertical Pod Autoscaler (VPA)

The VPA Operator automatically adjusts the CPU and memory resource requests (and limits) for pods based on historical and current usage patterns. Instead of adding more pods, it makes existing pods the right size.

VPA Components
+---------------+     +--------------+     +-------------------+
|  VPA          |     |  VPA         |     |  VPA Admission    |
|  Recommender  |     |  Updater     |     |  Controller       |
|               |     |              |     |                   |
| Analyses      |     | Evicts pods  |     | Sets correct      |
| historical &  |     | with wrong   |     | resource requests |
| current usage |     | resource     |     | on new pods       |
| -> generates  |     | values       |     | before admission  |
| optimal values|     |              |     | to node           |
+---------------+     +--------------+     +-------------------+

3.1 Update Modes

ModeBehaviourUse Case
OffOnly generates recommendations. Does not modify pods. Dry-run mode.Assess recommendations before enabling. Production auditing.
InitialSets resources only on newly created pods. Does not restart existing pods.Gradual adoption. Applies to new deployments only.
AutoEvicts and recreates pods with updated resource values. Full automation.Non-critical workloads where brief restarts are acceptable.
RecreateSame as Auto. Evicts pods so controllers recreate them with new values.Same as Auto. Functionally identical.

3.2 Example: VPA Configuration

apiVersion: autoscaling.k8s.io/v1
kind: VerticalPodAutoscaler
metadata:
name: my-api-vpa
spec:
targetRef:
apiVersion: apps/v1
kind: Deployment
name: my-api
updatePolicy:
updateMode: "Auto"
resourcePolicy:
containerPolicies:
- containerName: "*"
minAllowed:
cpu: 100m
memory: 128Mi
maxAllowed:
cpu: 2
memory: 2Gi
controlledResources:
- cpu
- memory

IMPORTANT: Do NOT use VPA and HPA on the same CPU/memory metrics simultaneously. They will conflict — HPA wants to add pods while VPA wants to resize them. You can safely combine VPA (managing CPU/memory) with KEDA (scaling on custom metrics like HTTP requests).
